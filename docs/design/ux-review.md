# Souvenir — UX and feature review

A snapshot of what the product does today (web PWA in `src/`, Expo app in
`apps/mobile/`) and the design language the icon set in `icons.svg` is built for.

## Product in one line

Collect places. Keep memories. Find your next adventure. A place becomes a
collectible card; a visit becomes a personal **edition** of that card; editions
group into **themed sets**; friends and a planner turn the collection into the
next outing.

## Core loop

Discover → Visit → Capture → Reveal → Collect → Recommend → Plan the next visit.

## Feature map by tab

| Tab | What the user does | Key surfaces |
| --- | --- | --- |
| Discover | Search "places or a feeling", browse the Los Angeles catalog by category, see appeal / frequency / window signals, open a place, save it, enter the planner | `discover-content.tsx`, `PlaceCard`, `RarityChips`, `FilterChip`, `SegmentedControl` (List / Map) |
| Collection | Been · Want to go · Sets; list, album and map views; search own collection; open an edition | `collection/page.tsx`, `EditionCard`, `SetCard`, `UnderlineTabs` |
| Capture (center action) | Take or pick a photo, confirm the place (location-first matching, AI suggestion optional), add date / companions / moment, save → card reveal | `capture-form.tsx`, `/api/capture/*`, `/api/editions` |
| Friends | Activity, shared "Want to go" lists, overlap with friends, outings | `shared-lists.tsx`, `/api/wishlists`, `/api/outings` |
| Profile | Stats, favorites, private tips, saved plans, Dropbox import, account and settings | `profile-content.tsx`, `plan-content.tsx`, `/api/import/dropbox` |

Planner ("Plan an afternoon") is reachable from Discover's header, a wishlist's
"Plan together", a place's "Add to plan" and Profile → Plans; it is not a tab.

## Distinctive concepts

- **Editions**: the same card frame for the shared place and for each personal
  visit; return visits get an "Edition 02" accent rather than a new card.
- **Three rarity signals**, never collapsed into one score: Appeal, Discovery
  frequency, Availability window.
- **Recommendation sentiment**: Recommend / It depends / Would skip, the only
  place the pastel green / yellow / pink scale appears.
- **Restrained reveal**: a short card flip and one light sweep; no confetti.
- **Provenance labels**: demo data and source attribution are always visible.

## Design language (from `beli-style-notes.md` and `globals.css`)

- One brand color, deep teal `#144F5D`; everything else is white and cool gray.
- Playfair Display for the wordmark, headings and place names; Inter for all
  functional text.
- Flat white rows, 1px dividers, 12px card corners, 8px thumbnails, fully
  rounded pills; shadows only on floating controls and sheets.
- Thin ~1.5px outline icons; filled or heavier only for the active tab; the
  center Capture tab is a filled teal circle.

## Observations from the review

1. The two clients disagree on icons: web uses Lucide (`Compass`, `Heart`,
   `UsersRound`, `UserRound`), mobile ships a hand-drawn `Icon.tsx` set with a
   bookmark for Collection. Collection means "heart" on web and "bookmark" on
   mobile.
2. The mobile app still ships Expo template assets (`icon.png`,
   `splash-icon.png`, `android-icon-*`, `react-logo*`, `tabIcons/`), so the
   installed app does not look like Souvenir.
3. The web app mark is a serif "s" in a circle; it says "brand" but not what the
   product does.
4. No icon existed for the concepts that make Souvenir different: edition, set,
   reveal, the three rarity signals, overlap and outings, so these fall back to
   text chips.

## Icon set

`icons.svg` is the preview; `public/icons/*.svg` are the 24px glyphs;
`public/icon.svg` and `public/icon-maskable.svg` are the app marks. All are
generated by `scripts/build-icons.mjs`.

Principles: 24-unit grid, 1.5 stroke, round caps and joins, `currentColor` so
the same file works in teal, gray or white; one metaphor per icon; no filled
variants except the active-tab treatment (fill at 12% + 2px stroke) and the
capture button.

| Group | Icons |
| --- | --- |
| Navigation | discover (compass), collection (stacked cards), capture (camera), friends, profile, plus |
| Places & memories | place (pin), edition (card with spark), set (album), reveal (spark), photo, revisit |
| Recommendation | recommend (check), depends (tilde), skip (minus) — pair with the sentiment fills |
| Rarity signals | appeal (heart), frequency (pulse), window (clock) |
| Social & planning | wishlist, shared-list, outing, plan, overlap, import |
| Utility | map, list, grid, search, filter, share, settings, check, close, back, chevron, more |

The app mark is a collectible place card with a pin and a caption line: the
Souvenir loop in one shape, readable at 16px.

Suggested follow-ups: replace the Lucide imports in `nav-items.ts` and the
mobile `Icon.tsx` paths with these glyphs so both clients match; rasterize the
app mark to the Expo `icon.png`, splash and Android adaptive assets.
